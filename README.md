# AcidRain

DCU C언어 기초 기말 프로젝트 \_ 산성비 타자 연습 게임을 직접 구현한 프로젝트입니다.

마감기한 : 26.12.05



깃 컨벤션 (모든 형식은 Type : 제목 \[제목은 반드시 영문으로 해야함])

Feture\_제목 :  새로운 파일을 만들거나 기능을 만들었을 때

Edit\_ : 기존 코드 혹은 파일의 내용을 수정하였을 때

Fix\_ : 버그를 해결하였을 때

Branch\_ : 브랜치를 건드리는 행위일 때

BackUp\_ : 이전의 깃내용으로 백업할 때

Remove\_ : 코드 혹은 파일이 삭제되었을 때



코드 컨벤션 (기본적으로 카멜 표기법을 따름)

반드시 함수의 기본적인 목적을 주석으로 적어둘 것.

Main함수가 들어 있는 GameManager 즉 Main코드의 경우

카멜 표기법을 따라 함수이름 중간에 \_를 사용하여 명명하지 않을 것

그러나

편리한 개발을 위한 헤더 코드를 사용할 때는

헤더이름\_함수이름 으로 명명할 것

ex)

콘솔을 편리하게 사용하기 위한 Console헤더

\-> 콘솔 커서이동 함수 Console\_Gotoxy

\-> 콘솔 초기화 함수 Console\_Clear()

\-> 콘솔 색상 변경함수 Console\_SetColor()
